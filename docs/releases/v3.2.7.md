## SuperTextView v3.2.7

本版本合入 PR #125、#126、#127，统一发布四个 ABI，不再区分 `.64` / `.99` 变体。

### 更新内容

- 修复 Java 动态创建视图的图片默认状态、图片点击取消、异步加载回调覆盖、文字描边与 GIF 可见性/挂载生命周期问题。
- 从源码重建 GIF native 库，支持 `armeabi-v7a`、`arm64-v8a`、`x86`、`x86_64`，校验 16 KB ELF LOAD/RELRO；无额外 `libc++_shared.so` 依赖。
- 去掉透明描边和透明纯色填充的无效绘制，保留圆角、按压态、渐变和图片背景。
- 增加最终 AAR / Maven 发布校验，拒绝空库、错误 ABI、测试资源泄漏和缺失 JNI keep 规则；保留 native 解码器授权声明。
- 正式 AAR 内置 JNI consumer keep 规则，不再声明宿主应用的名称或备份策略，避免 Manifest 合并冲突。

### 使用

```groovy
repositories { maven { url 'https://jitpack.io' } }
dependencies {
    implementation 'com.github.chenBingX:SuperTextView:v3.2.7'
}
```

JitPack 根据标签按需构建 Maven 产物。Release 附件同时提供经过校验的生产 AAR、Java 源码包、POM 和 SHA-256 校验文件。

Java/32 位 native 最低 API 19，64 位 native 最低 API 21。16 KB ELF 兼容不等同于最终 APK ZIP 对齐；应用还应检查其余 native 依赖及最终安装包。

### 验证与边界

57 项 Java 回归、36 项 Python 工具测试及正式 AAR 内容/消费应用构建通过；最终生产 AAR 的消费 APK 在 ARM64 真 16 KB 内核虚拟设备上通过 47 项 JNI 测试。此前同一 native 库另有 47 项 × 10 轮记录，以及 15 项真实框架/Skia UI 测试。具体记录与版本边界见下方文档。

未复现的 #91、#113、#77 和 #107 原报 3.2.3 实例仍保留；不将对照样例通过当作原问题修复，也不声称量化 GPU/CPU 性能提升。旧标签和旧发布产物没有改写。
